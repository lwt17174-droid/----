# 山野有橙 · 赣南脐橙品牌官网

一套零构建步骤的 HTML5、CSS3、原生 JavaScript 品牌官网原型。页面围绕清晨果园、赣南红土与当季鲜果组织内容，适合作为视觉设计稿和前端交互原型。

## 本地打开

双击 `启动官网.bat` 可用系统默认浏览器打开首页，也可以直接双击 `index.html`。页面不依赖 npm、框架或第三方 JavaScript 库。中文字体会优先请求 Noto Sans SC，离线或请求失败时自动回落到本机系统字体；上线前建议将获授权的字体文件放到本地并通过 `@font-face` 加载。

## 页面结构

顶部主导航使用普通页面链接，各栏目独立打开，不再通过滚动定位到同一页面里的长区块。每页都保留品牌导航与页脚，当前栏目会高亮。

| 页面 | 文件 | 内容 |
|---|---|---|
| 首页 | `index.html` | 品牌 Hero、产地承诺、各栏目的独立入口卡片与评价示例 |
| 鲜果商城 | `store.html` | 5 斤分享装、10 斤礼盒、企业团购与加入购物袋交互 |
| 产地故事 | `origin.html` | 赣南山地、红壤、采摘分选到冷链的滚动叙事 |
| 品质溯源 | `trace.html` | 产地路线示意、批次/检测报告/采摘日期说明 |
| 采摘节 | `harvest.html` | 独立活动页、倒计时与本地提醒反馈 |
| 联系购买 | `contact.html` | 商务与售后入口、咨询表单原型 |

**首页模块**：果实开场动画、吸顶导航、赣南果园主视觉、五项产地承诺和页面入口。开场动画在每个标签页会话中播放一次，可跳过。

**共享页脚**：品牌介绍、页面链接、售后与商务入口、二维码预留区。页脚链接也会跳转到独立页面。

## 动效与交互

- **页面导航**：六个独立 HTML 页面通过常规链接切换；吸顶导航玻璃效果、当前页面高亮和移动菜单在所有页面保持一致。
- **滚动**：IntersectionObserver 负责内容渐显、章节路线和溯源节点；一个被动滚动监听器在 requestAnimationFrame 中更新顶部进度与页脚轻视差。滚动只用于浏览当前栏目内容，不承担主栏目切换。
- **Hero**：桌面细指针上启用低幅光斑和摄影层视差；点击反馈使用小范围果汁波纹。
- **果实与购物袋**：产品图支持拖动视角倾斜、点击切果反馈、果汁粒子与飞入购物袋的 Web Animations API 动画，并更新数量和 Toast。当前产品使用单张照片，倾斜效果是原型表现，不是真实多角度 360° 商品模型。
- **声音**：默认静音。用户主动打开开关后，操作反馈才会尝试播放轻柔 Web Audio 提示音。
- **移动菜单**：汉堡键切换，支持 Escape 关闭、焦点状态与触摸选项。
- **联系表单**：浏览器端校验并显示演示反馈，目前不会发送数据；上线时接入真实邮件或 CRM 服务。
- **季节活动**：倒计时目前使用演示时间 `2026-11-15 09:00 +08:00`；按钮提醒为本地演示，不会写入账号或发送通知。

## 移动端适配

- 以窄屏为优先设置断点，导航改为全屏菜单，正文、商品列表、溯源卡片和页脚按单列/双列重排。
- 使用动态视口单位、`safe-area` 友好的固定布局和大于 44px 的主要点击目标；手势轨道保留原生横向滚动。
- 小屏关闭自定义光标与 Hero 指针视差，并将橙子雨粒子数量从 12 限制为 5。
- 页面内容仍可通过语义导航、锚点、键盘和屏幕阅读器访问。

## 性能与可访问性

- Hero 图片预加载且优先级高；下方图片使用 `loading="lazy"`。静态页面没有框架运行时与第三方动效依赖。
- 长滚动页面使用 IntersectionObserver，仅在元素接近视口时触发一次 reveal；动画主要使用 transform/opacity。
- `prefers-reduced-motion: reduce` 下关闭加载、自动横移、粒子与视差；`prefers-reduced-transparency` 下提供不模糊的实色导航背景。
- 页面使用语义化 `header`、`nav`、`main`、`section`、`article`、`footer`，图片配有描述性替代文本，按钮有可见焦点态、ARIA 名称与实时反馈。
- 声音默认关闭，提示音在用户操作并启用后才创建 AudioContext。
- 建议上线前压缩摄影图并以 `<picture>` 提供 AVIF/WebP/JPEG 回退；避免在低端移动设备上常驻视频或高频粒子。
